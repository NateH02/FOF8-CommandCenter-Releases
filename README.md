# FOF8 Command Center downloads

Official release downloads for FOF8 Command Center, supporting the Fire Football League (FFL) and Continental Football League (CFL).

This repository is for approved application downloads and release notes. Application source code, league files, player data, personal settings and signing keys are not stored here.

The in-app updater is being prepared and tested. No updater-enabled release has been published yet. Once available, existing users will receive a one-time bootstrap update; later approved releases can be offered inside the app.

Public downloads do not require a GitHub account. Publishing a release does not change or upload your personal league data.
