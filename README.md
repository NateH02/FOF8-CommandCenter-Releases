# FOF8 Command Center downloads

Official application downloads for Fire Football League (FFL) and Continental Football League (CFL).

[Download the latest release](https://github.com/NateH02/FOF8-CommandCenter-Releases/releases/latest)

## One-time update for older builds

1. Save your work and close Command Center and its tools.
2. Download **CommandCenter-Update.exe** from the release assets. The first updater-enabled download is about 167 MiB.
3. Run it and choose your **existing Command Center app folder**.
4. Reopen Command Center.

Use the executable asset, not GitHub's automatically generated Source code archives. Public downloads require no GitHub account. The updater replaces compatible program files with backup and readback checks, preserving league profiles, source paths, history, picks, gameplans, saved lineups, locks and custom assets.

## Later updates

The app checks after startup and periodically while open, then shows an in-app update notice. You can also use **Check for Updates** in Settings or the league launcher. Choose Update to download, verify and follow the normal save/close prompts. Later supported releases can use smaller downloads; their size depends on what changed. A closed app checks on its next launch.

This public repository contains approved program downloads and release notes only. Application source code, league files, player data, personal settings and signing keys are not uploaded.
